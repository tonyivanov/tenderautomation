# DEPLOYMENT.md — установка на новой машине

Пошаговая инструкция, как развернуть `b2bcenter-scout` с нуля. Тестировалось
на Windows 10/11. Под Linux/macOS придётся вручную адаптировать .bat-файлы
(см. секцию в конце).

## Что должно быть на машине

1. **Python 3.10 или новее.**
   - Скачать: https://www.python.org/downloads/
   - **При установке обязательно поставить галку «Add Python to PATH»** —
     без неё батники не найдут python.
   - Проверка: открыть cmd и набрать `python --version`.
     Должно вывести что-то вроде `Python 3.12.3`.

2. **Доступ в интернет** для:
   - скачивания pip-пакетов с pypi.org
   - скачивания Chromium (~150 МБ, один раз через Playwright)
   - запросов к b2b-center.ru

3. **Аккаунт GIS на B2B-Center** (логин + пароль, при необходимости 2FA).
   Нужен только для разведки карточек (`5_recon.bat`). Базовый сбор
   списков тендеров работает без авторизации.

## Шаг 1. Распаковать

Распаковать архив `b2bcenter-scout.zip` в любую папку. Рекомендую
короткий путь без пробелов и кириллицы, например:
```
C:\Tools\b2bcenter-scout\
```

Внутри должен быть набор `.bat`, `.py`, `.yaml` и папка `data/`.

## Шаг 2. Установка зависимостей

Двойной клик `1_setup.bat`. Что произойдёт:

1. Создаётся `venv\` (виртуальное окружение Python)
2. Устанавливаются пакеты из `requirements.txt`:
   - httpx (HTTP-клиент)
   - beautifulsoup4 + lxml (парсер HTML)
   - PyYAML (для словаря запросов)
   - playwright (для логина)
3. Скачивается Chromium для Playwright (~150 МБ, **только один раз**).

**Если выпало `ERROR: cannot create venv`:**
Python не установлен или нет в PATH. Переустановить Python с галкой
«Add Python to PATH», перезагрузить cmd.

**Если выпало `PIP INSTALL ERROR`:**
Скорее всего корпоративный прокси/файрвол режет pypi.org.
Открыть cmd в папке проекта и запустить вручную:
```
venv\Scripts\python.exe -m pip install -r requirements.txt
```
Точное сообщение об ошибке покажет, что не так.

**Если выпало `CHROMIUM DOWNLOAD ERROR`:**
Прокси режет скачивание Playwright. Проверь:
```
venv\Scripts\python.exe -m playwright install chromium
```
Если упорно не качается — настрой переменные окружения `HTTPS_PROXY`
до запуска. Для базового сбора списков Chromium не нужен, можно
пропустить этот шаг и пользоваться только `2b_search.bat` и `3_export.bat`.

## Шаг 3. Проверка

Двойной клик `0_check.bat` — покажет состояние окружения.

Что должно быть:
- Python 3.10+ в PATH
- venv создан
- Все 5 пакетов установлены
- Playwright виден

Если красные «NO» — вернись к Шагу 2 и устрани проблему.

## Шаг 4. Первый прогон

Двойной клик `2b_search.bat`.

Что произойдёт:
- Скрипт пройдётся по 94 запросам из `search_queries.yaml`
- На каждом запросе сходит на `https://www.b2b-center.ru/market/?f_keyword=...`
- Соберёт все совпадения в `data/b2bcenter.db`
- Применит prefilter (просто пометит как кандидаты)

**Время:** ~5-7 минут с паузами между запросами.

В консоли будут строки вроде:
```
=== Поиск: «PostgreSQL» ===
[info] фильтр сработал: 8 лотов в выдаче
[from=    0] получено:   8  новых:   8  всего за запрос: 8
[info] пауза перед следующим запросом: 3.4 сек
```

**Если выпадает `403 Forbidden`:**
Площадка временно режет частые запросы. Подожди 10-15 минут.
Если повторяется — открой `fetch_list.py`, найди константы
`SLEEP_MIN = 1.5` и `SLEEP_MAX = 4.0`, увеличь их в 2-3 раза.

**Если выпадает `[skip] выдача 7440 лотов > порога 1000`:**
Это норма. Сервер на каком-то запросе вернул общий листинг
вместо отфильтрованного — скрипт правильно пропускает такой запрос.

## Шаг 5. Выгрузка

Двойной клик `3_export.bat`. Создаст:
- `data/score100_tenders.txt` — кандидаты для разбора
- `data/all_tenders.txt` — полный дамп

## Шаг 6. (Опционально) Логин для разведки карточек

Если хочешь смотреть полные ТЗ внутри тендеров — нужен логин в B2B-Center.

1. Двойной клик `4_login.bat` — откроется реальный Chromium
2. Залогинься как обычно (логин/пароль, при необходимости 2FA)
3. Когда увидишь свой личный кабинет — переключись в чёрное окно cmd
   и нажми Enter
4. Сессия сохранится в `auth/auth_state.json`

Дальше можно запускать `5_recon.bat <id>` или `5_recon.bat --top 5`,
скрипт скачает HTML-карточку, сделает скриншот и положит в `data/recon/`.

Сессия живёт обычно сутки. Когда начнут прилетать ошибки про логин —
запусти `4_login.bat` заново.

## Регулярное использование

Обычный воркфлоу после установки:

```
1. 2b_search.bat       (~6 минут)
2. 3_export.bat        (мгновенно)
3. Загрузить data/score100_tenders.txt в чат с Claude
4. Получить шортлист
```

Если хочется чистый прогон без накопленных данных:
```
1. 9_reset_search.bat  (удалит search-тендеры из БД)
2. 2b_search.bat
3. 3_export.bat
```

## Перенос на другую машину

Если переносишь установленный скаут на новую машину:

1. Скопируй ВСЮ папку `b2bcenter-scout/` без `venv/` и без `auth/`
2. На новой машине запусти `1_setup.bat` — он создаст venv заново
3. Запусти `4_login.bat` для свежей сессии (если нужна разведка)
4. База `data/b2bcenter.db` переехала вместе с папкой — не нужно ничего
   качать заново

## Linux / macOS

Под Unix `.bat` не работают, но Python-скрипты — кроссплатформенные.
Аналог:

```bash
# 1_setup
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium

# 2b_search
source venv/bin/activate
python fetch_list.py --search-file search_queries.yaml

# 3_export
source venv/bin/activate
python export_for_review.py

# Аналогично login.py, recon_card.py, prefilter.py, reset_search.py
```

## Что в БД и как её смотреть глазами

`data/b2bcenter.db` — обычная SQLite. Открыть можно через:
- DB Browser for SQLite (https://sqlitebrowser.org/) — графический
- `sqlite3 data/b2bcenter.db` в командной строке

Структура таблицы `tenders`:
- `id` — номер тендера на площадке
- `section` — `commercial` / `fz223` / `search`
- `url` — полная ссылка
- `name` — заголовок
- `category` — категория площадки («ПО», «Серверы»...)
- `company_name`, `company_url` — заказчик
- `publish_date`, `deadline_date`
- `search_query` — по каким запросам нашли (через `;`)
- `prefilter_score` — `100` для кандидатов, `0` для отсеянных, `NULL` для нерелевантных
- `prefilter_hits` — какие ключи сработали
- `first_seen`, `last_seen` — даты появления в нашей БД

## Куда писать, если что-то сломалось

Сценарий «у меня не работает»:
1. Запусти `0_check.bat` — посмотри состояние окружения
2. Если в окружении всё ОК, но скрипт падает — открой cmd в папке проекта
   и запусти руками с детальным выводом:
   ```
   venv\Scripts\python.exe fetch_list.py --search-file search_queries.yaml
   ```
3. Скопируй вывод и пришли в чат Claude — обычно это починка в одну строку.
