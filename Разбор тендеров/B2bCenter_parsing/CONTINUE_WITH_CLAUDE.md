## Типовые задачи и как их формулировать

**«Разбери свежие тендеры»**
→ Просто кинь `score100_tenders.txt`. Claude знает, что делать.

**«Добавь в словарь новые ключи»**
→ «Добавь в search_queries.yaml следующие запросы: ...
   Сделай новый архив со всеми файлами»

**«Нашёл шум — этот тип тендеров не наш»**
→ Кинь несколько примеров: «Эти не должны попадать: #4434807, #4434808.
   Что добавить в фильтр?»

Claude посмотрит, найдёт корень проблемы (обычно — слишком короткий ключ
в словаре) и предложит починку.

**«Загляни в карточку тендера X»**
→ После `5_recon.bat <id>` положи в чат файлы из `data/recon/<id>.html`
   и `data/recon/<id>.report.json`. Claude разберёт ТЗ и оценит, наш ли это.

**«Что нового добавилось в базе с прошлой выгрузки?»**
→ Кинь старый и новый `score100_tenders.txt`. Claude найдёт diff по ID
   и покажет только новые.

## Как обновить словарь руками

`search_queries.yaml` редактируется в обычном текстовом редакторе.
Формат YAML:

```yaml
queries:
  - "новый ключ"
  - "ещё один"
```

После правки запускай `2b_search.bat` — обойдёт по новому списку.

Что НЕ стоит добавлять (опыт трёх прогонов):
- Слова короче 5 символов на латинице (IDS, MES, ESB, ERP, CRM, SAP) —
  ловят артикулы
- Слова короче 4 символов на кириллице (1С, АБС, ВКС) — ловят размеры
  и марки в неликвиде
- «оказание услуг по», «выполнение работ по» — слишком общие
- «АСУТП», «АСУ ТП» — это не наш профиль

Что стоит добавлять при появлении нового кейса:
- Точные имена вендоров: «Veeam», «FortiGate», «Atlassian»
- Длинные точные фразы: «программно-аппаратный комплекс»
- Названия продуктов: «АПКШ Континент», «Гарда DBF»
- Имена законов: «152-ФЗ», «187-ФЗ»

## Как делать частые регулярные прогоны

Если хочется крутить раз в день/неделю — просто гоняй цепочку:
```
2b_search.bat → 3_export.bat → diff с прошлой выгрузкой
```

Скрипт инкрементальный: тендеры, которые уже были, не дублируются —
к ним только дописывается новый запрос в `search_query` (через `;`).

Чтобы видеть только свежие, можно делать так перед запуском:
```
copy data\score100_tenders.txt data\score100_PREV.txt
```
А после прогона дать Claude оба файла — `_PREV` и новый. Он скажет,
что появилось.

## Если что-то совсем сломалось

1. Запусти `0_check.bat` — проверка окружения
2. Открой `data/b2bcenter.db` через DB Browser, посмотри сколько там тендеров
3. Кинь Claude:
   - вывод `0_check.bat`
   - последние 50 строк лога ошибки
   - содержимое `search_queries.yaml`
4. Чаще всего проблема: антибот (403), сломалась вёрстка площадки (надо
   подкрутить парсер), или неудачно правил yaml (синтаксис).
