============================================
WORKFLOW — ежедневный разбор за 10 минут
============================================

Этот файл — короткий чек-лист для рутинной работы.
Полная инструкция по установке — в README.txt.
Контекст для Клода — в PROJECT_CONTEXT.md.

--------------------------------------------------
ЕЖЕДНЕВНЫЙ ЦИКЛ
--------------------------------------------------

[ ] 1. Двойной клик на 2_fetch.bat
       (~3 секунды если новых мало, до 2 минут при первом запуске)
       
[ ] 2. Двойной клик на 3_export.bat
       Появятся файлы в data\ :
         - all_tenders.txt        (все активные тендеры)
         - score100_tenders.txt   (кандидаты по префильтру)
       
[ ] 3. Открой Claude (claude.ai), создай новый чат.
       
[ ] 4. К первому сообщению прикрепи ТРИ файла:
         - PROJECT_CONTEXT.md       (один раз — контекст ГИС и Bidzaar)
         - BRIEF_FOR_CLAUDE.md      (один раз — как анализировать)
         - score100_tenders.txt     (что анализировать)
       
       (опционально: all_tenders.txt — если хочешь чтобы Клод
        дополнительно проверил на утечки префильтра)
       
       Текст сообщения:
       ----
       Привет! Это файлы про мониторинг тендеров для ГИС.
       Прочитай контекст и бриф, затем разметь
       score100_tenders.txt по эшелонам ⭐ / 🟡 / 🟠.
       Категорию 🔴 не выводи.
       ----
       
[ ] 5. Получишь от Клода размеченный список:
         ⭐ Прямые попадания  → проверить ТЗ, готовить заявку
         🟡 Стоит изучить    → открыть, прочитать ТЗ, решить
         🟠 Тяжёлая конкур.  → подать на всякий случай если есть ресурс
       
[ ] 6. По каждой ссылке открыть карточку на сайте:
       https://bidzaar.com/process/light/{id}
       Прочитать ТЗ, посмотреть бюджет, дедлайн, требования.
       
[ ] 7. По интересным — связаться с продактом / BD-руководителем
       для подачи заявки.

--------------------------------------------------
РАЗ В НЕДЕЛЮ
--------------------------------------------------

[ ] Просмотри все_tenders.txt глазами, выборочно. 
    Может что-то новое появилось, на что префильтр не натренирован.

[ ] Если нашёл закономерность — открой keywords.yaml,
    добавь ключевое слово в whitelist_keywords или blacklist.
    Сохрани, запусти 2_fetch.bat — правила перепримутся.

--------------------------------------------------
ЧТО ДЕЛАТЬ ЕСЛИ
--------------------------------------------------

Скрипт пишет "401 Unauthorized" / "403 Forbidden":
    Сессия Bidzaar протухла. Удали playwright_state.json,
    запусти 2_fetch.bat — снова откроется браузер для логина.

Браузер открылся на логине, но не закрывается:
    Возможно, Bidzaar изменили формат хранения токена.
    В таком случае — обратись к разработчику или новому
    Клоду в чате с приложенным PROJECT_CONTEXT.md.

Префильтр пропускает что-то очевидно интересное:
    Открой keywords.yaml в Блокноте, добавь ключевое слово
    в whitelist_keywords. Запусти 2_fetch.bat ещё раз.

Префильтр выдаёт слишком много шума:
    Открой keywords.yaml, добавь шумное слово в blacklist
    (помни — blacklist приоритетнее whitelist).
