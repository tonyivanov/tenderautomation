============================================
BIDZAAR-SCOUT — комплект для команды ГИС
============================================

Что это: автоматический мониторинг тендеров на bidzaar.com,
помогает находить тендеры, релевантные профилю Git in Sky.


--------------------------------------------------
С ЧЕГО НАЧАТЬ — навигация по файлам
--------------------------------------------------

Если ты ВПЕРВЫЕ открыл этот комплект:
   → Читай этот README до конца. Это установка и первый запуск.

Если уже всё стоит и хочешь рутинно работать:
   → Открывай WORKFLOW.txt — там дневной чек-лист.

Если разбираешь тендеры в чате с Клодом:
   → Прикрепляй PROJECT_CONTEXT.md и BRIEF_FOR_CLAUDE.md
     к чату вместе с tenders-файлами.

Если что-то сломалось или хочешь развивать систему:
   → PROJECT_CONTEXT.md — там вся техническая история проекта,
     включая нюансы Bidzaar API и план Дня 2 (LLM-анализ).


--------------------------------------------------
ЧТО ВНУТРИ КОМПЛЕКТА
--------------------------------------------------

Скрипты (запускаются батниками, руками не редактируем):
  fetch_list.py         сбор списка тендеров
  prefilter.py          префильтр по ключевым словам
  export_for_review.py  выгрузка в txt для разбора в чате
  auth.py               автоматическая авторизация (Playwright)

Конфиг (можно править в Блокноте):
  keywords.yaml         whitelist и blacklist ключевых слов

Кнопки запуска:
  1_setup.bat           разовая установка
  2_fetch.bat           ежедневный сбор + префильтр
  3_export.bat          выгрузка в txt для чата с Клодом

Документация:
  README.txt            этот файл — установка и первый запуск
  WORKFLOW.txt          ежедневный чек-лист на 10 минут
  PROJECT_CONTEXT.md    полный контекст для нового Клода
  BRIEF_FOR_CLAUDE.md   короткий бриф для аналитической задачи

  requirements.txt      список Python-библиотек (для setup)

После первого запуска появятся:
  venv\                 Python-окружение (не трогай)
  playwright_state.json сохранённая сессия Bidzaar (НИКОМУ не показывай!)
  data\bidzaar.db       база с тендерами
  data\token_cache.json кэш access-токена


--------------------------------------------------
УСТАНОВКА — делается один раз
--------------------------------------------------

1. Убедись, что Python установлен. Открой cmd, набери:
       python --version
   Должно показать 3.10 или выше. Если нет — поставь с python.org,
   ОБЯЗАТЕЛЬНО поставь галочку "Add Python to PATH" при установке.

2. Двойной клик на 1_setup.bat.
   Откроется чёрное окно. Скрипт:
     - создаст Python-окружение (папка venv)
     - поставит библиотеки (requests, PyYAML, Playwright)
     - скачает Chromium для Playwright (~300 МБ, минута-две)
   Жди надписи "SETUP COMPLETED!".


--------------------------------------------------
ПЕРВЫЙ ЗАПУСК — настройка авторизации
--------------------------------------------------

Двойной клик на 2_fetch.bat.

1. Сначала откроется НАСТОЯЩЕЕ окно Chromium.
2. В нём страница логина Bidzaar.
3. Введи логин и пароль ГИС-аккаунта на Bidzaar
   (если не знаешь — спроси у тех, у кого есть доступ).
4. Дойди до главной страницы — окно само закроется через
   2-5 секунд после успешного логина.
5. Скрипт продолжит работу в чёрном окне командной строки —
   начнёт качать ~2700 активных тендеров (~2 минуты).

После этого сессия сохранена в playwright_state.json.
Все следующие запуски — без браузера.

ВАЖНО: playwright_state.json — это твоя сессия Bidzaar.
Никому его не отдавай: тот, у кого этот файл, может работать
в Bidzaar от имени твоего аккаунта.


--------------------------------------------------
ЕЖЕДНЕВНЫЙ ЗАПУСК
--------------------------------------------------

Двойной клик на 2_fetch.bat → новые тендеры в базу
Двойной клик на 3_export.bat → выгрузка в txt-файлы

Дальше — по чек-листу WORKFLOW.txt.


--------------------------------------------------
ЕСЛИ СЕССИЯ ПРОТУХЛА
--------------------------------------------------

Симптом: 2_fetch.bat пишет ошибку 401 / 403, или
"Сохранённая сессия не сработала".

Лечение:
  1. Удали файл playwright_state.json вручную.
  2. Запусти 2_fetch.bat — снова откроется окно браузера
     для ручного логина.

Сессия в Bidzaar обычно живёт несколько недель.


--------------------------------------------------
ПРАВКА КЛЮЧЕВЫХ СЛОВ
--------------------------------------------------

Открой keywords.yaml в Блокноте:
  whitelist_keywords  — слова-кандидаты (score=100)
  blacklist           — слова-отсев (score=0)

Регистр не важен. Сравнение по подстроке: "инфраструктур"
поймает "инфраструктура", "инфраструктурой" и т.д.

Поправил → запустил 2_fetch.bat → правила перепримутся
к ВСЕЙ базе (не только к новым тендерам).


--------------------------------------------------
ЧАСТЫЕ ОШИБКИ
--------------------------------------------------

"python: command not found":
    Python не в PATH. Переустанови с python.org с галочкой
    "Add Python to PATH".

"Не удалось дождаться логина за 5 минут":
    Браузер открылся, но логин не завершился.
    Запусти 2_fetch.bat ещё раз.

Браузер открылся, ты залогинился, но окно не закрывается:
    Возможно, Bidzaar поменяли формат хранения токена.
    Открой PROJECT_CONTEXT.md, раздел "Технические детали
    Bidzaar" — там описано как искать. Или приложи
    PROJECT_CONTEXT.md к чату с Клодом и опиши проблему.


--------------------------------------------------
ЧТО ВНУТРИ БАЗЫ ДАННЫХ
--------------------------------------------------

data\bidzaar.db — обычный SQLite-файл. Открыть можно в:
  - DB Browser for SQLite (бесплатно, удобно)
  - DataGrip
  - VS Code с плагином SQLite

Полезные SQL-запросы (структуру см. в PROJECT_CONTEXT.md):

  -- свежие кандидаты
  SELECT publish_date, company_name, name
  FROM tenders WHERE prefilter_score = 100
  ORDER BY publish_date DESC;

  -- по конкретному заказчику
  SELECT publish_date, name FROM tenders
  WHERE company_name LIKE '%Cloud.ru%';
