C) JSON / JSONL файлы (простота, читаемость без БД)
D) CSV файлы (удобно для Excel/Sheets-анализа)

[Answer]: X все-таки логично держать инструмент на сервере с веб-интерфейсом. Тогда действия разных специалистов по анализу тендеров будут фиксироваться в одном логе. И его лучше сделать JSONL
